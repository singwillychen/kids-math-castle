# 公主與青蛙的數學城堡

給 4–7 歲小朋友的互動式加減法與心算練習網站（純 HTML / CSS / JS，不需安裝、不需後端）。

直接用瀏覽器打開 `index.html` 就能使用。

## 功能

- **年齡選擇**：中班（5 以內）、大班（10 以內）、小一（20 以內，含湊十、借十）
- **🍎 數蘋果**：拖曳或點蘋果，加法放進籃子、減法餵給青蛙
- **🔟 十格框**：數數量、湊滿 5／10、小一的湊十法動畫
- **🐸 數線跳跳**：青蛙往右跳是加、往左跳是減；進位／退位題示範「先跳到 10」的大跳法
- **⚡ 心算練習**：可選加法／減法／混合、5／10／15 題、計時挑戰；答錯可看算盤圖解
- **🧮 算盤教室**：自由撥珠＋撥數挑戰、算式的逐步撥珠動畫（5 的好朋友、10 的好朋友）
- **🎁 我的寶盒**：答對得星星，每 5 顆換一張貼紙
- **👨‍👩‍👧 家長專區**（需大人回答乘法題才能進入）：
  - 累計題數、一次答對率、練習天數、最近 7 天練習量
  - 各題型表現（進位加法、退位減法、湊十……）與「需要加強」標示
  - 針對弱點的練習建議、依年齡的建議學習路線
  - 最近答錯的題目，可一鍵看算盤解法
  - 設定：年齡、每回合題數；匯出 CSV、清除紀錄、星星歸零
- **🔈 語音唸題**（可開關）、**🔔 音效**（可開關）
- **實體鍵盤**：數字鍵輸入、Enter 送出、Backspace 刪除

星星、設定與練習紀錄只存在這台裝置的瀏覽器（localStorage），不會上傳。

```
│   ├── rewards.js     我的寶盒

```
